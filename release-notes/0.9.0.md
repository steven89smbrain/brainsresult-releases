# BrainsResult 0.9.0 — beta pertama

Rilis publik pertama BrainsResult: tugas, catatan, file dan keuangan dalam satu aplikasi desktop, untuk pribadi maupun tim kantor. Panduan: [docs/](../docs/README.md).

## Isi

**Tasks**
- Daftar, Board (kolom bisa diatur, juga per proyek), Calendar, Task database; filter & pencarian.
- Proyek, prioritas, tag, checklist, tugas berulang, pengingat (juga saat jendela tertutup).
- **Notes**: catatan Markdown sebagai file biasa, dengan tag dan pratinjau.
- **Attachments**: file di folder sungguhan, pratinjau gambar & PDF, dikaitkan ke tugas.

**Finance**
- Akun dalam berbagai mata uang dengan kurs bertanggal, transaksi, transfer, bukti / struk.
- Kategori bertingkat, anggaran bulanan, target tabungan, tagihan berulang.
- Laporan per periode, kekayaan bersih, ekspor CSV.

**Umum**
- Beberapa workspace (mis. Pribadi & Usaha), tab, command palette `Ctrl K`, tema terang / gelap.
- Inbox notifikasi dan ringkasan pagi.
- Backup manual & otomatis (opsional dengan password), restore, pindah ke server.
- **Kantor**: server database MySQL bersama (terenkripsi), pengguna & peran, sign-in dengan durasi login, akses per orang, komentar, penanggung jawab tugas, kunci edit. Butuh lisensi — selama beta, minta [lisensi beta](../README.md#edisi-selama-beta).
- Update otomatis.

## Catatan beta

- Installer belum ditandatangani: Windows menampilkan SmartScreen saat pertama dipasang (*More info* → *Run anyway*).
- Tampilan dalam Bahasa Inggris; panduan dalam Bahasa Indonesia.
- Edisi Free: 2 workspace aktif di komputer ini; server database hanya bisa dilihat tanpa lisensi.
- Laporkan masalah lewat Settings → *Help* → *Report a problem…*.
