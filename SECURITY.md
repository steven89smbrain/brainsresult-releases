# Keamanan

Bila Anda menemukan celah keamanan di BrainsResult (misalnya cara membuka data orang lain, melewati sign-in, atau memalsukan lisensi), **jangan** membuat issue publik.

Laporkan secara privat lewat tab **Security → Report a vulnerability** di repo ini, atau email TODO security@….

Sertakan versi aplikasi, langkah untuk mengulanginya, dan dampaknya. Jangan sertakan data pribadi atau data keuangan sungguhan. Kami membalas dalam 7 hari kerja.
