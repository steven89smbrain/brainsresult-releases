# BrainsResult

Aplikasi desktop untuk **tugas, catatan, file dan keuangan** dalam satu tempat — untuk pribadi maupun tim kantor (dengan server database bersama).

## Unduh

➡️ **[Unduh versi terbaru](../../releases/latest)** — pilih file `BrainsResult-<versi>-setup.exe` di bagian *Assets*.

| | |
|---|---|
| Sistem | Windows 10 / 11, 64-bit |
| Ruang disk | ± 500 MB |
| Internet | Tidak wajib untuk edisi Free. Dipakai untuk update otomatis dan aktivasi lisensi |

## Instalasi

1. Jalankan file `…-setup.exe` yang diunduh.
2. Bila muncul **"Windows protected your PC"** (SmartScreen), klik **More info → Run anyway**. Peringatan ini muncul pada aplikasi baru yang belum banyak diunduh.
3. Ikuti langkah instalasi, lalu buka BrainsResult. Wizard pertama kali membantu memilih tempat data (komputer ini atau server database kantor).

Data Anda disimpan di folder yang Anda pilih, **bukan** di folder program, sehingga update atau install ulang tidak menghapusnya.

## Update

BrainsResult memeriksa versi baru secara otomatis, mengunduhnya di belakang layar, lalu memasangnya saat aplikasi dibuka ulang. Riwayat perubahan setiap versi ada di halaman **[Releases](../../releases)**.

Pada kantor yang memakai server database bersama, perbarui semua komputer ke versi yang sama.
