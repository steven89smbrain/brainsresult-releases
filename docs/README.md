| [3. Tasks, Notes & Attachments](03-tasks.md) | Tugas, proyek, Board, Calendar, tugas berulang, pengingat, catatan Markdown, file |
| [4. Finance](04-finance.md) | Akun, transaksi, transfer, kategori, anggaran & target, tagihan, laporan, mata uang |
