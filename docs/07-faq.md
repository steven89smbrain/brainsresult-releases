# 7. Pertanyaan umum

**Windows bilang "Windows protected your PC".**
Installer beta belum ditandatangani. Klik *More info* → *Run anyway*. Unduh hanya dari halaman [Releases](https://github.com/steven89smbrain/brainsresult-releases/releases) resmi.

**Apakah data saya dikirim ke internet?**
Tidak. Data ada di komputer atau server Anda sendiri. Lihat [PRIVACY.md](../PRIVACY.md).

**Saya lupa password.**
Administrator bisa mereset password pengguna lain (*Manage workspaces* → *Users*). Administrator yang lupa passwordnya sendiri memakai **recovery code** (dibuat lebih dulu di Settings → *Account*) lewat *Forgot password?* di layar login.

**Kenapa saya keluar sendiri?**
Administrator mengatur berapa lama login berlaku dan keluar otomatis saat tidak dipakai (*Sign-in security*). Layar login menyebut alasannya.

**Workspace ketiga tidak bisa dibuat.**
Edisi Free menyimpan 2 workspace aktif di komputer ini. Arsipkan satu, atau minta lisensi beta.

**Data dari server tidak berubah.**
Tekan `F5` (atau klik kanan → *Refresh data*).

**Bagaimana melaporkan masalah?**
Settings → *Help* → *Report a problem…*. Lampirkan hasil *Copy diagnostic info* (tanpa password, alamat server atau nama pengguna). Jangan menyertakan data keuangan atau pribadi sungguhan.

**Apakah ada versi Mac atau Linux?**
Belum; direncanakan setelah versi 1.0.
