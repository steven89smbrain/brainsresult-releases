# 3. Tasks, Notes & Attachments

## Tugas

- **Membuat:** tombol *New task*, `Ctrl K` lalu ketik judulnya, atau klik ganda tanggal di *Calendar*.
- **Detail** (klik tugas, panel kanan): status, prioritas, proyek, tanggal & jam jatuh tempo, pengulangan, pengingat, tag, catatan, checklist, catatan & file terkait.
- **Selesai:** centang tugas, atau seret ke kolom *Done* di Board. Hapus bisa dibatalkan lewat *Undo* di notifikasi.

| Tampilan | Kegunaan |
|---|---|
| *Home* | Ringkasan: hari ini, terlambat, akan datang, progres proyek |
| *All tasks* | Daftar per status, dengan filter (status, prioritas, proyek, tag, tanggal) dan pencarian |
| *Board* | Kolom per status; seret kartu antar kolom |
| *Calendar* | Kalender bulanan |
| *Task database* | Tabel semua tugas |

## Proyek & kolom Board

*Manage projects*: buat, ganti warna, arsipkan proyek. Kolom Board bisa diatur untuk seluruh workspace atau **per proyek** (*Columns*); kolom *Done* selalu terakhir.

## Tugas berulang & pengingat

- *Repeat*: harian, mingguan, bulanan, dst. Saat tugas selesai, tugas berikutnya dibuat otomatis.
- *Reminder*: tepat waktu, 15 menit, 1 jam atau 1 hari sebelumnya. Pengingat muncul sebagai notifikasi Windows walau jendela tertutup (aplikasi berjalan di tray).

## Notes (catatan Markdown)

Catatan adalah file `.md` biasa di folder data. Editor punya toolbar (tebal, judul, daftar, checklist, kode, tautan), pratinjau, tag di bagian atas, dan bisa dikaitkan ke tugas. *Copy Notes* menyalin catatan sebagai teks berformat untuk email atau chat.

## Attachments (file)

File tersimpan di folder sungguhan (`<folder data>\workspaces\<id>\attachments`), jadi juga bisa dibuka lewat Explorer. Buat folder, unggah dengan seret-lepas, ganti nama, pindah, pratinjau gambar & PDF, dan kaitkan file ke tugas. Satu tugas bisa punya folder sendiri.
