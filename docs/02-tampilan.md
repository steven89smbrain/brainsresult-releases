# 2. Mengenal tampilan

| Area | Fungsi |
|---|---|
| **Rail kiri** | Pindah fitur: *Workspace* (rumah), *Tasks*, *Finance*. Di bawahnya lonceng notifikasi, tema terang / gelap, Settings |
| **Menu fitur** | Halaman fitur yang aktif, kotak cari, dan pemilih workspace di atas |
| **Tab** | Setiap halaman terbuka di tab. `Ctrl + klik` = buka di tab baru; seret tab untuk mengurutkan. Tab diingat per workspace |
| **Isi** | Halaman yang dibuka; detail tugas / transaksi tampil di panel kanan |
| **Status bar** | Koneksi aktif, siapa yang login, jumlah tugas terbuka, mata uang dasar, edisi, versi |

## Command palette (`Ctrl K`)

Cari halaman, tugas, catatan dan perintah apa pun. Ketik juga untuk membuat sesuatu:
- `Telepon klien` → *New task: “Telepon klien”*.
- `Makan siang 45000` → catat pengeluaran; `Honor +2000000` → pemasukan.

## Shortcut

| Shortcut | Aksi |
|---|---|
| `Ctrl K` | Command palette |
| `Ctrl T` / `Ctrl W` | Tab baru / tutup tab |
| `Ctrl B` | Tampilkan / sembunyikan menu fitur |
| `Ctrl J` / `Ctrl Alt B` | Panel bawah / panel kanan |
| `F5` | Muat ulang data (juga lewat klik kanan → *Refresh data*) |

## Workspace

Workspace memisahkan data, misalnya *Pribadi* dan *Usaha*. Pemilih workspace ada di atas menu fitur. Buat, ganti nama, arsipkan atau backup workspace di *Manage workspaces*. Edisi Free menyimpan 2 workspace aktif di komputer ini.

*Manage features* menyalakan / mematikan fitur per workspace (mis. workspace tanpa Finance).

## Notifikasi

Lonceng di rail membuka inbox: pengingat tugas & tagihan, tugas terlambat, anggaran hampir habis, komentar, dan pemberitahuan sistem (backup gagal, update siap). Settings → *Notifications* mengatur mana yang muncul sebagai notifikasi Windows, hanya di inbox, atau tidak sama sekali, serta jam ringkasan pagi.

## Settings

Tampilan (tema, huruf, kepadatan), akun & password, notifikasi, berjalan di latar belakang, update, bantuan (*Report a problem*, *Copy diagnostic info*), dan *About*.
