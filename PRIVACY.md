# Pernyataan Privasi — BrainsResult

**Versi beta · berlaku sejak 2026-10-27**

*English version below.*

**Ringkas: BrainsResult tidak mengirim data Anda kepada Kami.** Tidak ada akun BrainsResult, tidak ada iklan, tidak ada telemetri.

| Data | Disimpan di | Dikirim ke |
|---|---|---|
| Tugas, catatan, file, keuangan, pengguna | Komputer Anda, atau server database / penyimpanan file (MySQL, S3, WebDAV, folder jaringan) yang **Anda** pilih | Hanya ke server yang Anda atur |
| Password | Hanya hash (scrypt) di database Anda; password server / penyimpanan dienkripsi Windows di komputer Anda | Tidak ke mana pun |
| Log aplikasi | `%APPDATA%\BrainsResult\logs` di komputer Anda, tanpa password, alamat server atau nama pengguna | Tidak ke mana pun, kecuali Anda sendiri menyalinnya ke laporan masalah |

**Koneksi internet yang dibuat aplikasi:**
- **Pemeriksaan pembaruan** ke GitHub (halaman rilis BrainsResult): GitHub menerima alamat IP dan versi aplikasi, seperti saat Anda membuka situs web.
- **Server yang Anda atur sendiri** (database, penyimpanan file).
- **Server lisensi** BrainsResult — belum dipakai selama beta. Nantinya hanya menerima kode lisensi, ID instalasi / perangkat dan email pembeli.
- **Laporan masalah** membuka halaman GitHub di browser Anda; isi laporan Anda yang menentukan.

Pertanyaan: halaman [Issues](https://github.com/steven89smbrain/brainsresult-releases/issues).

# Privacy Statement — BrainsResult

**Beta version · effective 2026-10-27**

**In short: BrainsResult does not send your data to Us.** There is no BrainsResult account, no advertising, no telemetry.

| Data | Stored on | Sent to |
|---|---|---|
| Tasks, notes, files, finances, users | Your computer, or the database server / file storage (MySQL, S3, WebDAV, network folder) **you** choose | Only the servers you set up |
| Passwords | Only a hash (scrypt) in your database; server / storage passwords encrypted by Windows on your computer | Nowhere |
| App log | `%APPDATA%\BrainsResult\logs` on your computer, without passwords, server addresses or user names | Nowhere, unless you copy it into a problem report |

**Internet connections the app makes:**
- **Update checks** to GitHub (the BrainsResult release page): GitHub receives your IP address and the app version, as when you visit a website.
- **Servers you set up yourself** (database, file storage).
- **The BrainsResult license server** — not used during the beta. Later it only receives license codes, installation / device ids and the buyer's email.
- **Report a problem** opens GitHub in your browser; what you write is up to you.

Questions: the [Issues](https://github.com/steven89smbrain/brainsresult-releases/issues) page.
